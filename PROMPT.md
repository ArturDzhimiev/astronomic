# Промпт для Claude Code

Скопируй текст ниже целиком и вставь в Claude Code (в терминале, находясь внутри
папки `astronomic-recetario`, куда ты распаковал архив).

---

Это статический сайт (index.html + data.js, без сборки и зависимостей) —
двуязычный рецептурник ресторана с поиском. Нужно задеплоить его в интернет,
чтобы он открывался по ссылке с любого телефона.

Сделай следующее:
1. Проверь, что index.html корректно открывается локально (python3 -m http.server).
2. Инициализируй git-репозиторий в этой папке, если его ещё нет.
3. Задеплой сайт как статический на Vercel (используй `vercel` CLI: `npx vercel --prod`,
   через npx, чтобы не требовать глобальной установки). Если Vercel CLI попросит
   логин — покажи мне инструкцию, как залогиниться (обычно через браузер), и подожди
   моего подтверждения.
4. Если Vercel недоступен или что-то пойдёт не так — как запасной вариант
   задеплой на Netlify (`npx netlify-cli deploy --prod`) или через GitHub Pages
   (создать репозиторий на GitHub через `gh repo create`, запушить, включить Pages
   в настройках через `gh api` или веб-интерфейс).
5. В конце пришли мне финальную публичную ссылку на сайт и подтверди, что она
   открывается (curl -I на неё, статус 200).

Важно: это простой статический HTML/JS сайт без бэкенда, сборщика и npm-зависимостей —
не нужно ничего собирать webpack/vite, просто задеплоить файлы как есть.

---

## Что нужно от тебя (человека) во время работы Claude Code

- Если появится запрос на логин в Vercel/Netlify/GitHub — это нормально,
  просто пройди авторизацию в открывшемся браузере.
- Если попросит создать аккаунт — Vercel и Netlify бесплатны для такого использования,
  можно зарегистрироваться через GitHub/Google одним кликом.

## После деплоя

Ты получишь постоянную ссылку вида `https://astronomic-recetario.vercel.app`
(или похожую) — открывается на любом устройстве, включая iPhone Safari,
без скачивания файлов.
